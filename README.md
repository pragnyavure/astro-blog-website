# Astro Blog Website

A modern blog website built using Astro and Tailwind CSS.

## Features
- Responsive UI
- Dark / Light mode toggle
- Dynamic blog pages
- Reusable Astro components
- Contact page
- Markdown blog support

## Tech Stack
- Astro
- Tailwind CSS
- TypeScript
