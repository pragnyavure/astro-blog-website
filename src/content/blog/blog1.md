# Why Astro?

Astro is a modern frontend framework focused on performance and simplicity.

It helps developers create extremely fast websites by shipping less JavaScript to users.

## Key Features

- Fast performance
- Component-based architecture
- Easy routing
- Markdown support
- SEO friendly

## Why Developers Like Astro

Astro allows developers to build clean and scalable frontend applications with modern tooling.

It is especially useful for blogs, portfolios, and content-focused websites.
